# my-first-site — портфолио Димона

Статический сайт на HTML, CSS и JavaScript. Сборка не требуется.

## Файлы проекта

- `index.html` — главная страница портфолио.
- `project1.html` — страница проекта «Первый сайт».
- `project2.html` и `project2.js` — интерактивная демонстрация.
- `project3.html` и `project3.js` — демонстрация цветовой палитры.
- `style.css` — общие стили.
- `script.js` — общие интерактивные функции и переключение темы.
- `my-photo.jpg`, `photo.jpg` — изображения.

## Запуск на компьютере

Открой `index.html` в браузере. Для проверки можно также запустить локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация

Это статический сайт: команда сборки не нужна, папка публикации — корень репозитория (`.`). Для сохранения кода в закрытом GitHub-репозитории и автоматического публичного размещения можно подключить репозиторий к Netlify. После предоставления Netlify доступа к репозиторию новые коммиты смогут автоматически публиковаться.

## Важно

Форма контактов используется в учебных целях. Несмотря на наличие кода отправки через Formspree, получение сообщений не гарантируется.

Не размещай в репозитории пароли, API-ключи и другие секретные данные.
